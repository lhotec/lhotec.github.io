# Publicar app-ads.txt em lhotec.github.io

## Prompt

Preciso criar um repositório público no GitHub para publicar o arquivo `app-ads.txt` do AdMob na raiz do domínio `https://lhotec.github.io/`. Você tem autorização para criar o repositório e fazer o push.

### Contexto

- O AdMob não conseguiu verificar o app "Fio Certo - Cálculo Elétrico" (Android) porque `https://lhotec.github.io/app-ads.txt` retorna 404.
- O AdMob procura o arquivo **somente na raiz do domínio**, então ele precisa estar num repositório chamado exatamente `lhotec.github.io` (site de usuário do GitHub Pages).
- Já existe um site de projeto em `https://lhotec.github.io/lho-tech-site/` (repositório `lhotec/lho-tech-site`). **Não altere, renomeie nem apague esse repositório.** Ele continua funcionando normalmente ao lado do novo.

### O que fazer

1. **Conferir o ambiente**
   - Verifique se o `git` está instalado e qual conta do GitHub está autenticada.
   - Verifique se o `gh` (GitHub CLI) está instalado e autenticado (`gh auth status`). Ele não estava instalado na última verificação. Se continuar ausente, pergunte se devo instalar (`winget install GitHub.cli` e depois `gh auth login`) ou se prefiro criar o repositório manualmente pelo site.
   - A conta precisa ser **`lhotec`**. Se for outra, pare e me avise.
   - Confira se o repositório `lhotec/lhotec.github.io` já existe. Se existir, me mostre o conteúdo antes de mexer em qualquer coisa.

2. **Criar a pasta local** `C:\Projects\lhotec.github.io` com estes arquivos:

   `app-ads.txt` (UTF-8 **sem BOM**, final de linha LF, uma linha só e uma quebra de linha no final):
   ```
   google.com, pub-3387260683084704, DIRECT, f08c47fec0942fa0
   ```
   - `pub-3387260683084704` é o ID de editor do AdMob da conta.
   - **Não** incluir `pub-3940256099942544`, que é o ID de teste do Google.
   - Não use `Set-Content`/`Out-File` do PowerShell 5.1 para gravar esse arquivo, porque eles podem adicionar BOM. Use a ferramenta Write ou o bash.

   `index.html` (redireciona a raiz para o site existente):
   ```html
   <!doctype html>
   <html lang="pt-BR">
   <head>
     <meta charset="utf-8">
     <title>LHO Tech</title>
     <meta http-equiv="refresh" content="0; url=/lho-tech-site/">
     <link rel="canonical" href="https://lhotec.github.io/lho-tech-site/">
   </head>
   <body>
     <p>Redirecionando para <a href="/lho-tech-site/">LHO Tech</a>…</p>
   </body>
   </html>
   ```

   `README.md` curto explicando que o repositório existe para servir o `app-ads.txt` na raiz do domínio e redirecionar para `/lho-tech-site/`.

3. **Criar o repositório e publicar**
   - `git init -b main`, adicionar os arquivos e fazer o commit.
   - Com o `gh`: `gh repo create lhotec/lhotec.github.io --public --source . --push`.
   - Sem o `gh`: me peça para criar o repositório **público** `lhotec.github.io` em https://github.com/new (vazio, sem README), depois configure o `git remote add origin https://github.com/lhotec/lhotec.github.io.git` e faça `git push -u origin main`.

4. **Ativar o GitHub Pages** (branch `main`, pasta `/`)
   - Com o `gh`: confira com `gh api repos/lhotec/lhotec.github.io/pages`. Se retornar 404, ative com
     `gh api -X POST repos/lhotec/lhotec.github.io/pages -f "source[branch]=main" -f "source[path]=/"`.
   - Sem o `gh`: me oriente a ir em Settings → Pages → "Deploy from a branch" → `main` / `(root)`.

5. **Verificar** (o deploy pode levar alguns minutos)
   - `curl -i https://lhotec.github.io/app-ads.txt` deve retornar **200**, `Content-Type: text/plain` e exatamente a linha acima.
   - `https://lhotec.github.io/` deve redirecionar para `/lho-tech-site/`.
   - `https://lhotec.github.io/lho-tech-site/` deve continuar retornando 200.

6. **Me passar os próximos passos manuais**
   - Play Console → Presença na loja → Detalhes do app → o site do desenvolvedor deve ser `https://lhotec.github.io` ou `https://lhotec.github.io/lho-tech-site/`. Os dois servem, porque o AdMob sempre verifica a raiz do domínio.
   - AdMob → Apps → Fio Certo → app-ads.txt → "Verificar se há atualizações". A verificação pode levar até 24h.

### Restrições

- Não commite nada além de `app-ads.txt`, `index.html` e `README.md`.
- Nunca publique keystore, `key.properties`, JSON de conta de serviço nem qualquer credencial.
- Não mexa no repositório `lhotec/lho-tech-site`.
